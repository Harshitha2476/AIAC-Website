THEME 01 // INDIC NLP Explore Pod 01 Dashboard →

Regional NLP & Indic LLMs

Research Objective

Constructing compute-efficient subword tokenization, morphological segmentation, and calibrated cross-lingual pseudo-labeling pipelines for low-resource Indic languages, with a specialized focus on regional Kannada administrative and dialect corpora.

Key Technical Directions
  • • Byte-pair encoding (BPE) vs SentencePiece subword boundary analysis on Indic unicode scripts
  • • Parameter-efficient fine-tuning (LoRA / QLoRA) on open Kannada instruction datasets
  • • Temperature-calibrated teacher-student knowledge distillation for low-resource sentiment transfer
  • • Multilingual evaluation against standard IndicGLUE benchmarks
Active & Proposed Projects
  • Kannada Morphological Segmentation Baseline Active
  • Cross-Lingual Pseudo-Labeling with Calibrated Confidence Validating
Core Stack: PyTorch Hugging Face IndicBERT IndicNLP

THEME 02 // EDGE & VISION Explore Pod 02 Dashboard →

Edge AI & Vision Systems

Research Objective

Investigating ultra-low latency computer vision inference under strict thermal, compute, and memory limits on embedded edge hardware, enabling continuous real-time video telemetry stream perception.

Key Technical Directions
  • • Post-training quantization schemes (INT8/FP16) with calibration dataset optimization
  • • TensorRT graph compilation and CUDA kernel fusion for embedded NVIDIA Jetson platforms
  • • Zero-copy memory ring buffers for high-framerate IP video stream ingestion
  • • Edge benchmark profiling tracking frame throughput, latency jitter, and thermal throttle
Active & Proposed Projects
  • INT8 Quantized Object Detection on Jetson Active
  • Multi-Camera Video Stream Anomaly Pipeline Proposed
Core Stack: TensorRT CUDA YOLOv8 DeepStream

THEME 04 // HEALTHCARE & BIO-SIGNALS Explore Pod 04 Dashboard →

Healthcare & Bio-Signals

Research Objective

Developing noise-resilient deep learning architectures for physiological time-series interpretation, focusing on single-lead electrocardiogram (ECG) beat anomaly identification and electroencephalogram (EEG) spectral telemetry.

Key Technical Directions
  • • Lightweight 1D dilated convolutional networks for real-time cardiac beat classification
  • • Wavelet-based baseline wander and muscle artifact removal in noisy non-clinical recordings
  • • Validation on PhysioNet MIT-BIH Arrhythmia benchmark databases
  • • Patient data anonymization and privacy-preserving clinical time-series representation
Active & Proposed Projects
  • 1D-CNN Single-Lead ECG Anomaly Detection Active
  • Artifact Removal & Spectral Power in Mobile EEG Proposed
